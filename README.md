# Animal Care

**Animal Care** — онлайн-помощник для заботы о домашних животных и интернет-магазин зоотоваров, который помогает выбрать и купить подходящие товары, а также узнать об особенностях ухода в зависимости от возраста, породы и потребностей питомца.

## О проекте
Веб-приложение сочетает полноценный интернет-магазин для владельцев собак и кошек (каталог, фильтры и поиск, карточка товара, корзина, оформление заказа, личный кабинет и админ-панель) и базу знаний по уходу с персональным подбором под параметры питомца.

## Основные функции
- Главная страница, каталог товаров с поиском и фильтрацией, страница товара
- Корзина, расчёт суммы и оформление заказа (с имитацией оплаты)
- Регистрация, авторизация, личный кабинет (профиль питомца, избранное, история заказов)
- База знаний по уходу и персональный подбор товаров по возрасту, породе и потребностям питомца
- Административная панель для управления товарами, категориями, заказами и пользователями

## Технологический стек
- **Дизайн и Frontend:** Figma / Stitch, HTML5, CSS3, JavaScript (адаптивная вёрстка)
- **Backend и API:** Node.js, Express.js, REST API
- **База данных:** PostgreSQL
- **Инструменты и деплой:** Git, GitHub, Postman, DevTools, Vercel + Render

## Распределение ролей в команде
- **Индира** — дизайн-система, макеты и Frontend (главная, каталог, карточки, страница товара, адаптив).
- **Тарлан** — Backend, REST API, авторизация, обработка заказов и связка с БД и Frontend.
- **Малика** — база данных PostgreSQL и административная панель.
- **Улжан** — корзина, избранное, поиск и фильтры, оформление заказов, тестирование, документация и презентация.
