# Animal Care — интернет-магазин для питомцев

Командный проект: единый сайт магазина товаров для собак и кошек. Покупатель может найти подходящий товар, добавить его в корзину и оформить заказ. Отдельная админ-панель и складская система в проект не входят.

## Что должно работать

- Главная страница с категориями и подборкой товаров.
- Каталог с поиском и фильтрами по категории, виду питомца и цене.
- Карточка товара с фото, описанием, ценой и остатком.
- Регистрация и вход покупателя, профиль питомца для подбора товаров.
- Корзина: добавление, изменение количества, удаление и пересчёт суммы.
- Оформление заказа с контактами и адресом; сохранение заказа и позиций в PostgreSQL.
- Понятные сообщения об успехе и ошибках.

## API

Ожидаемые маршруты и поля описаны в [docs/api-contract.md](docs/api-contract.md). Согласуйте их между frontend и backend перед интеграцией.

## Запуск и проверка

Инструкции запуска нужно дополнить после добавления backend/frontend кода и файлов конфигурации. Сквозные проверки описаны в [docs/testing-checklist.md](docs/testing-checklist.md); укажите результаты после запуска приложения.

## Участники

- **Индира:** дизайн, страницы магазина, каталог и адаптивный frontend.
- **Тарлан:** Node.js/Express API, авторизация и связь с PostgreSQL.
- **Ответственный за БД:** схема, демонстрационные данные и ER-диаграмма.
- **Улжан:** интеграция частей, README и проверка пользовательских сценариев.

## Структура

- `frontend/` — интерфейс магазина.
- `backend/` — сервер и REST API.
- `database/` — PostgreSQL схема и демонстрационные данные.
- `docs/` — API-контракт, инструкции и результаты проверок.

Не добавляйте пароли и токены в Git. Используйте локальный `.env` и публикуйте только `.env.example` без секретов.
