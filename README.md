# Animal Care — интернет-магазин для питомцев

Командный проект: единый магазин товаров для собак и кошек. Покупатель должен найти подходящий товар, добавить его в корзину и оформить заказ. Отдельная админ-панель и самостоятельная складская система в проект не входят.

## Требования

- Главная с категориями и подборкой товаров; каталог с поиском и фильтрами по категории, виду питомца и цене.
- Страница товара с фото, описанием, ценой и остатком.
- Регистрация/вход и профиль питомца.
- Корзина с добавлением, изменением количества, удалением и пересчётом.
- Оформление заказа с контактами и адресом, сохранение заказа и позиций в PostgreSQL.
- Понятные сообщения об успехе и ошибках.

## Текущие части

- Backend: сервер и инструкция запуска находятся в [`backend/backend/`](backend/backend/README.md). API-контракт собран в [`docs/api-contract.md`](docs/api-contract.md).
- База: SQL-скрипты находятся в [`database/database/`](database/database/schema.sql) в ветке `database`.
- Frontend: ветка `frontend` пока содержит только заглушку; каталог, корзина и карточки ещё предстоит добавить и подключить к API.

## Запуск и проверка

Следуйте инструкции backend для локального запуска API. Общую команду запуска frontend + backend и порядок чистой установки базы добавим после объединения веток. Сквозные проверки перечислены в [`docs/testing-checklist.md`](docs/testing-checklist.md); отмечайте их пройденными только после фактического запуска.

## Роли

- **Индира:** интерфейс магазина, каталог, карточка товара и адаптивность.
- **Тарлан:** Node.js/Express API, вход покупателя и PostgreSQL.
- **Ответственный за БД:** схема, тестовые данные и ER-диаграмма.
- **Улжан:** интеграция, README и проверка сценариев.

## Безопасность

Не добавляйте реальные пароли и токены в Git. Храните локальные секреты в `.env`; публикуйте только пример без значений секретов.
