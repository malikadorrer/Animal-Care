# Проверки пользовательского сценария

Статус всех пунктов оставлен «Не проверено», поскольку frontend/backend реализации пока нет в соответствующих ветках. Заполните результат и дату после запуска приложения.

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| T01 | Запуск на чистой базе по README | Приложение и тестовые данные запускаются | Не проверено — нет кода запуска |
| T02 | Главная и каталог | Видны категории и список товаров | Не проверено — frontend отсутствует |
| T03 | Поиск и фильтры категории/вида/цены | Выдаются только подходящие товары | Не проверено — frontend/backend отсутствуют |
| T04 | Карточка товара | Фото, описание, цена и остаток отображаются | Не проверено — frontend отсутствует |
| T05 | Регистрация и вход | Успешный вход; неверные данные дают понятную ошибку | Не проверено — backend отсутствует |
| T06 | Добавить питомца | Питомец связан с вошедшим покупателем | Не проверено — backend отсутствует |
| T07 | Добавить товар в корзину | Появляется позиция и пересчитывается сумма | Не проверено — frontend/backend отсутствуют |
| T08 | Изменить количество и удалить позицию | Количество и итог обновляются | Не проверено — frontend/backend отсутствуют |
| T09 | Заказ с заполненной корзиной | Заказ и позиции сохранены в PostgreSQL, показано подтверждение | Не проверено — backend отсутствует |
| T10 | Пустая корзина | Заказ не создаётся, показано объяснение | Не проверено — backend отсутствует |
| T11 | Нет товара/недостаточный остаток | Ошибка понятна; остаток и корзина не повреждены | Не проверено — backend отсутствует |
| T12 | Обновить страницу и открыть мои заказы | Каталог и заказ доступны после перезагрузки | Не проверено — реализация отсутствует |

## Запись дефекта

Для ошибки укажите ID проверки, ветку/коммит, шаги воспроизведения, ожидаемый и фактический результат. Секреты, реальные пароли и личные данные не включайте.
