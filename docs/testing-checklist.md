# Проверки пользовательского сценария

Backend уже есть в ветке `backend`, но frontend в ветке `frontend` пока не загружен. Сквозные проверки ниже ещё не запускались; после объединения частей укажите дату и фактический результат.

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| T01 | Запуск приложения и БД по итоговой README | Приложение стартует на чистой базе | Не проверено |
| T02 | Главная, каталог и фильтры | Видны товары; поиск и фильтры работают | Не проверено — ждёт frontend |
| T03 | Карточка товара | Фото, описание, цена и остаток видны | Не проверено — ждёт frontend |
| T04 | Регистрация и вход | Успех; неверные данные дают сообщение | Не проверено |
| T05 | Добавление питомца | Питомец сохраняется у вошедшего покупателя | Не проверено |
| T06 | Корзина: добавление, изменение, удаление | Позиции и сумма пересчитываются | Не проверено — сквозной прогон ждёт frontend |
| T07 | Заказ из заполненной корзины | Заказ и позиции сохраняются; остаток уменьшается | Не проверено |
| T08 | Пустая корзина | Заказ не создаётся, возвращается понятная ошибка | Не проверено |
| T09 | Недостаточный остаток / отсутствующий товар | Заказ отклоняется без частичного изменения данных | Не проверено |
| T10 | После обновления открыть каталог и мои заказы | Данные загружаются снова | Не проверено — ждёт frontend |

## Дефекты

Для каждого дефекта укажите ID проверки, ветку и коммит, шаги воспроизведения, ожидаемый и фактический результат. Не добавляйте реальные пароли и личные данные.
